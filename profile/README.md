## About
We are a non-commercial, non-profit team of indie developers focused on absolute control over code. We prefer clean architecture, minimal dependencies, and diving deep into low-level systems.

Vorx Labs is powered entirely by a passionate team of next-generation developers under 18. We don't limit ourselves to a single language or a specific field. From low-level engineering and custom game frameworks to web ecosystems, async backend tools, and automation software — we select the best stack for the job and build powerful digital solutions from scratch.
